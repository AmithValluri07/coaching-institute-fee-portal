# Deployment & Setup Guide
**Coaching Institute Fee Tracking & Parent Portal System**

---

## Prerequisites
* Python 3.8+ installed on your system.
* A modern web browser (Chrome, Edge, or Safari) for viewing the frontend interface.

---

## Step-by-Step Execution Guide

### 1. Clone or Open Project Workspace
Open your workspace folder (`coaching-fee-system`) in Visual Studio Code.

### 2. Run Backend Python Engines
Open your terminal in VS Code and execute the modular simulation scripts to verify business logic:
* **Fee Ledger Engine**:
  ```bash
  py ledger_engine.py
